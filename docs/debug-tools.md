# Debug専用ポーズ・履歴・JSON編集

Debug x64のFPSで使用します。Releaseでは履歴収集・F1ポーズ・コマ送り／戻し・JSON編集画面をコンパイル対象から外しています。

## キー操作

|操作|キー|動作|
|---|---|---|
|ポーズ／再開|F1|ゲーム進行を止め、マウスカーソルを表示してImGuiを操作できます。再度F1で再開します。|
|1コマ戻す|`,`（カンマ）|ポーズ中、保存済みの1つ前の状態へ戻ります。|
|1コマ進める|`.`（ピリオド）|ポーズ中、保存済みの次の状態へ進みます。履歴の最新位置なら1/60秒だけ処理します。|

FPS Debug Toolsウィンドウのボタンからも同じ操作ができます。数値やテキストを編集中はカンマ／ピリオドのショートカットを無効にして、入力文字として扱います。アプリにフォーカスがあるときだけキーボード操作を受け付けます。

ポーズ中はクリックしてもFPSマウス操作へ戻りません。カーソルで各Debugウィンドウを操作してください。再開後のクリックが意図せず射撃にならないよう、押しっぱなしの射撃入力は解除待ちになります。ポーズ中の自由移動カメラは追加していません。

## コマ戻しの範囲

直近300コマのCPU状態をメモリへ保存します。60fpsなら約5秒、フレームレートによって時間範囲は変わります。履歴の最古より前には戻れません。Restartやシーン変更で履歴は消去します。

Playerの位置・向き・HP・武器状態、敵の位置・AI・HP／部位破壊、発射済みの弾／爆弾、Face Shatter／Chunkの状態、スポーン進行と乱数、武器取得状態、StageClear／経過時間、ADSを復元します。コマ戻しで破壊前の部位や消える前の弾も復元対象になります。履歴を戻してからF1で再開すると、戻した時点から新しい履歴へ分岐し、それより後の旧履歴は破棄します。

通常実行中の履歴は各フレームの実際の更新結果です。その履歴を前後する場合は保存済み状態を再表示します。最新位置での新しいコマ送りだけが1/60秒固定です。新しいコマ送り中はマウスが解放されたままなので、新規の移動・射撃操作は入力しませんが、敵・弾・リロードなどは1コマ進みます。

## JSONの数値を変更する

1. F1でポーズします。
2. **FPS Debug Tools** の **JSON File** で **Enemies / Weapons / Stage** を選びます。
3. **Document** を開き、対象のIDや配列を展開します。
4. 数値欄を変更します。数値配列の0／1／2はXYZやRGBの各成分です。ON／OFFのboolも変更できます。ID・ファイル名・Enumの文字列や行の追加削除はこの画面では編集しません。
5. **Validate, Save & Restart** を押します。
6. 既存ローダーで全関連設定を検証してから保存し、ステージをポーズ状態で再開始します。新しい数値はその再開始から適用されます。
7. F1でプレイを再開します。

対象は `resources/Data/enemies.json`、`resources/Data/weapons.json`、現在使用中のステージJSONです。通常のStageは `resources/levels/stage01/stage01.json`、Fallback時は `resources/levels/fps_spawns.json` になります。

変更は入力しただけではゲームやディスクへ反映されません。不正値はError欄に理由を出し、元ファイルを維持します。整数であるべきspawnCount等へ小数を入力した場合も検証で拒否します。座標や攻撃力などは、元JSONで整数表記されていても小数へ変更できます。

**Reload JSON / Discard edits** は未保存の編集を捨て、ディスクから読み直します。未保存の編集がある間はファイル切替を無効にします。外部エディタやBlenderで元ファイルが更新された場合は上書きを拒否するため、Reloadしてから編集し直してください。

保存直前の内容を元ファイル名＋`.debug-backup`へ保管します。検証済みの一時ファイルをWindowsの置換APIで反映するため、検証失敗時には元ファイルを変更しません。バックアップは次の成功した保存で更新されます。

BlenderからStageを再Exportすると、この画面で変更したStage JSONの値はBlender側の値で上書きされます。恒久的なStage配置変更は.blend側へも反映してください。Enemy／Weapon定義はBlender Exportでは上書きされません。

## 確認

`tools/test-debug-tools.ps1` は履歴の前後移動・上限・分岐、AI／部位HP／弾／破片／武器／スポーン／乱数／Stage状態の値コピー復元、JSON数値型、検証、バックアップ、ファイル置換、外部変更の競合検出を検証します。

ゲーム画面でのF1入力、マウス表示、ImGuiのクリック操作、巻き戻した破片の見た目は実操作未確認です。手元では次を確認してください。

- [ ] F1で敵・弾・スポーン・経過時間が止まり、カーソルが表示される。
- [ ] ポーズ中はSceneをクリックしても勝手に再開しない。
- [ ] カンマで前の状態へ戻り、ピリオドで次の状態へ進む。
- [ ] 敵の部位破壊前後、敵弾の命中前後、StageClear前後を行き来できる。
- [ ] 数値の小数点入力がコマ送りにならない。
- [ ] 保存して再開始後、Enemyの体格・速度やWeaponの数値が反映される。
- [ ] 不正値は保存できず、JSONの元ファイルが維持される。
- [ ] Releaseでは新しいDebug画面もF1ポーズも動作しない。
